Detailed Description

template<typename T, int Capacity>
class Queue< T, Capacity >

A circular queue template class with a fixed capacity.

When the queue is full, adding a new item overwrites the oldest item.

Template Parameters
TThe type of elements stored in the queue.
CapacityThe maximum number of elements the queue can hold.
